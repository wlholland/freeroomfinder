Connect once, then just ask. Your assistant checks BYU's class schedule and tells you which rooms are open. Free, read-only, no login.

Server URL __BASE__/mcp

Connect your assistant

  1. In Claude, open Settings → Connectors and click Add custom connector.
  2. Paste the server URL and name it BYU Rooms.
  3. Start a new chat and ask for a room.

Don't see Connectors? Your plan may not allow custom connectors. Try the No MCP tab instead.

Run this in your terminal:

claude mcp add --transport http byu-rooms __BASE__/mcp

Add this to your MCP config (in Cursor, that's ~/.cursor/mcp.json). No API key needed.

{
  "mcpServers": {
    "byu-rooms": {
      "url": "__BASE__/mcp"
    }
  }
}

Paste this into any AI agent that can make web requests. It explains the API, so there's nothing to install. Add what you're looking for on the last line.

I want to find an empty classroom at BYU. Use the FreeRoomFinder public API (read-only JSON, no login or API key):

- GET __BASE__/api/v1/buildings
  Building codes and names. Only buildings with has_cached_rooms=true return results.
- GET __BASE__/api/v1/rooms/available?date=YYYY-MM-DD&start=HH:MM&duration=MINUTES&building=CODE
  date defaults to today, start is 24-hour time (required), duration is 15-960 minutes, building is optional.
- GET __BASE__/api/v1/rooms/{BUILDING:room}?date=YYYY-MM-DD
  One room's open windows for a day, e.g. HBLL:2214 (URL-encode the colon).

All times are Mountain Time (America/Denver). A room counts as free when no class is scheduled there; it is a walk-in space, not a reservation. Full docs: __BASE__/api/v1/docs
