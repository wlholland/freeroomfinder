Ask your AI for an empty room

FreeRoomFinder runs an MCP server, so Claude and other AI assistants can look up open BYU classrooms for you. Ask something like "find me a quiet room in the library tomorrow at 3 for two hours" and it checks the live class schedule. It's read-only and free, with no login or API key.

1 Copy the server URL

__BASE__/mcp

2 Add it to your assistant

Claude (claude.ai or the desktop app)

  1. Open Settings → Connectors and choose Add custom connector.
  2. Name it BYU Rooms and paste the URL above.
  3. Start a new chat. Allow the connector the first time Claude asks.

Custom connectors need a plan or workspace that allows them. If you don't see the option, use one of the other methods below.

Claude Code

claude mcp add --transport http byu-rooms __BASE__/mcp

Other MCP clients

Any client that supports remote MCP servers over Streamable HTTP will work, with no authentication. Many clients, like Cursor, use a config like this:

{
  "mcpServers": {
    "byu-rooms": {
      "url": "__BASE__/mcp"
    }
  }
}

3 Ask away

Paste this into a new chat and change the building, day, and time to what you need:

Use the BYU Free Room Finder tools to find me an empty classroom in the Harold B. Lee Library (HBLL) tomorrow from 2:00 to 4:00 PM. List the rooms that are open the whole time first, then any that are only open for part of it.

No MCP? Paste this instead

Agents that can make web requests (Claude Code, Cursor, and other coding agents) can use the public JSON API directly. Paste this prompt and fill in the last line:

I want to find an empty classroom at BYU. Use the FreeRoomFinder public API (read-only JSON, no login or API key):

- GET __BASE__/api/v1/buildings
  Building codes and names. Only buildings with has_cached_rooms=true return results.
- GET __BASE__/api/v1/rooms/available?date=YYYY-MM-DD&start=HH:MM&duration=MINUTES&building=CODE
  date defaults to today, start is 24-hour time (required), duration is 15-960 minutes, building is optional.
- GET __BASE__/api/v1/rooms/{BUILDING:room}?date=YYYY-MM-DD
  One room's open windows for a day, e.g. HBLL:2214 (URL-encode the colon).

All times are Mountain Time (America/Denver). A room counts as free when no class is scheduled there; it is a walk-in space, not a reservation. Full docs: __BASE__/api/v1/docs

My request: [e.g. a quiet room in the library tomorrow from 2 to 4 pm]

Good to know

  • "Free" means no class is scheduled. Rooms aren't reserved for you and may be locked or used for other events.
  • Only loaded buildings have results. The AI can see buildings someone has already searched on the main page. If a building comes back empty, search it there once and ask again.
  • Weekly schedule, not specific dates. A date is treated as its weekday, so holidays and finals aren't reflected. Sundays return nothing.
  • Times are Mountain Time. Capacity and amenities aren't available from BYU, so the AI can't filter on them.
